# µLib™ API Reference

Modular ES6 (`.mjs`) web library system: utilities, i18xe localization, sounds, sprites, E-Ink rendering and a complete panel/workspace GUI.

This HTML reference is **generated from JSDoc comments** in `src/µLib/` (American English). Regenerate with:

```bash
npm run docs
```

For installation, the bilingual project README, packaging and release history see the [µLib™ repository](https://github.com/mamekudz/microLib). Published online at [mamekudz.github.io/microLib](https://mamekudz.github.io/microLib/).
